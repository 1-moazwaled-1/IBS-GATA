# IBS-GATA — Marketing Agency Website

A modern and responsive marketing agency website built with React and Tailwind CSS.

## 🚀 Live Demo

https://ibs-gata.vercel.app/

## 📌 About The Project

IBS-GATA is a responsive marketing agency website designed to introduce the company, showcase its services, and help potential customers discover its products.

The website also includes a small e-commerce section where users can browse products and view product details.

## 🎯 The Problem & Solution

### The Problem

The company did not have a website where potential customers could learn more about the company, explore its services, or discover its products.

This made it harder for the company to build an online presence, introduce its brand to new customers, and increase potential sales.

### The Solution

I designed and developed a modern, responsive website that gives the company a professional online presence and makes its information easily accessible to potential customers.

The website allows visitors to:

- Learn more about the company
- Explore the services it provides
- Browse available products
- View product details
- Add products to a shopping cart
- Contact the company directly when they are interested in a product or service

The goal was to create a website that not only presents the company professionally, but also makes it easier for potential customers to discover what the company offers and take the next step toward making a purchase or contacting the company.

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/1-moazwaled-1/IBS-GATA.git
```

Navigate to the project directory:

```bash
cd IBS-GATA
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
